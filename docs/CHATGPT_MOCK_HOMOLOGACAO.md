# Homologação ChatGPT em MOCK

Em 24/10/2026, o teste relatou descoberta de 17 ferramentas do servidor MCP e chamadas bem-sucedidas via Secure MCP Tunnel. Esta evidência é pontual, não garante que o túnel continue ativo. Nunca confundir números fictícios de Natal, clientes ou pedidos com dados reais.

Para o transporte stdio, utilize apenas uma instância do tunnel-client por túnel. O comando de execução do servidor é `node --env-file=.env scripts/start-mock.mjs` na pasta do clone. Não publicar credenciais ou liberar ferramentas reais de escrita.

Referência: https://github.com/openai/tunnel-client/blob/master/docs/configuration.md.
